Getting started

  1. Configuration: File > New Configuration. Add a Screen, a Layout, a Window (toolbar or Edit menu); set the window pixelArea and scalingFactor. Add a User Application, choose its Window and its DF Path.
  2. Definition File: File > New Definition File. Add a Layer, then right-click the scene to add widgets at the click point, or use the toolbar. Containers accept children: right-click a container, or drag a node onto it in the hierarchy.
  3. Scene: drag to move, corner handles resize, arrows nudge (Shift x10), Delete removes, wheel zooms, middle-drag or Space-drag pans, F fits, G grid, S snap.
  4. Inspector: hover a parameter name for its specification description; the About section explains the selected widget; red values would not fit the binary form.
  5. Linking: the Definition File ApplicationId must equal the user application applicationId; the user application inspector checks it and previews the layers in the window; the Definition File root lists who references it.
  6. Files: Ctrl+S saves (.bin = binary Part 1-7 form, otherwise XML). Ctrl+Z / Ctrl+Y undo and redo. F1 opens help on the selection.
