A661_ANIMATION_ROTATION (AnimationRotation)

Categories: Utility

The objective of this widget is to provide a means for performing a rotation animation on one widget. The widget referenced in this AnimationRotation widget must be defined in the Definition File before the AnimationRotation widget. The behavior for this widget is specified in Section 3.2.11. Axis of rotation: Angles are measured in degrees. Rotation is around the Z-axis. The ZERO degree is along the X-axis in the positive direction. The positive direction of angles is in the counter-clockwise direction from the X-axis. x y z + Direction and Number of turns: The animation from FromAngle to ToAngle is performed clockwise or counter- clockwise, as specified by the Direction parameter. The NumberOfTurns parameter specifies how many times the FromAngle threshold is crossed. The rotation values do not change the ARINC 661 target widget parameter values. The result of the rotation is added to the coordinate system transformation specified by the widget position and rotation. 2. If this animation receives a A661_DEACTIVATE, it will put back the state of the rotation transformation to the identity transform (0 angle rotation).
