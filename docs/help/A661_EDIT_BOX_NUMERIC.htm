A661_EDIT_BOX_NUMERIC (EditBoxNumeric)

Categories: Graphical representation, Interactive, Text string

The EditBoxNumeric widget enables editing a numeric value. A crew member can modify the numeric value using input devices. Since a numeric value is used, the CDS is able to increment the value. The widget can receive a number of incremental values or a numeric key value. When the EditBoxNumeric is in edit mode, the CDS may report all modifications made to the value of the edited string, some of the modifications, or just the confirmed value (after a crew member validation). The UA controls this option through the "ReportAllChanges" parameter.
