A661_MAPHORZ_PANEL (MapHorz_Panel)

Categories: Container, Map management, Graphical Representation

This container can be embedded into a MapHorz_Source widget. The X and Y parameters provide this real world position data. Their interpretation is dependent on the MapDataFormat. The screen location resulting from the projection of the X and Y parameters defines the origin of the MapHorz_Panel's children. Its aim is to provide geographic-aware interactivity, e.g., it is possible to add a few buttons close to a waypoint or a text entry close to an airport. The unit for the widgets within the container remains the standard hundredth of mm A661 unit. The size of the widget can be used by the CDS to manage specific placement policies.
