A661_SYMBOL_TOGGLE_BUTTON (SymbolToggleButton)

Categories: Graphical representation, Interactive, Text string

A SymbolToggleButton widget is a button with two stable states with a symbol and possibly text. Note: When aligning the symbol to the button widget, the symbol representation's bounding rectangle should be used; see the BOUNDING_RECT command in Section 5.2.4.14.
