A661_POP_UP_MENU_BUTTON (PopUpMenuButton)

Categories: Graphical representation, Interactive, Text string

The PopUpMenuButton widget has a static part (a Button) which, when selected by a crew member, causes the display of the popup part of the PopUpMenuButton. The popup part of the PopUpMenuButton is similar to a PopUpMenu widget. The UA is responsible for defining the position of the popup part of this widget. The OpeningMode parameter can be used to further control the position of the popup part relative to the static part. The method for closing the popup part of the widget is implementation dependent.
