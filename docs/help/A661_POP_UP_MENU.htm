A661_POP_UP_MENU (PopUpMenu)

Categories: Graphical representation, Interactive, Text string

The PopUpMenu is a menu intended for temporary display on top of all layers in its window. PopUpMenu has no static part. PopUpMenu displays a list of selectable string entries, each of which represents either a control selection or sub-menu item. Crew interaction with a menu entry can cause another PopUpMenu to appear. PopUpMenu visibility should be managed by the CDS using implementation dependent logic. The OpeningMode parameter allows the UA some control over the position of the PopUpMenu. However, the CDS is responsible for defining the size and position of the PopUpMenu, as part of the implementation dependent look and feel.
