A661_FOCUS_LINK (FocusLink)

Categories: Utility

The FocusLink widget is used to define a NextFocusedWidget sequence that crosses between two separate layers. The interactive widgets and the FocusLinks are chained together using the NextFocusedWidget parameters in the normal way. focus sequences. To the Pilot the focus would move through the sequence 17, 18, 19, 58, 59. Although the FocusLinks (20 and 57) exist in the chain of NextFocusedWidgets, the highlight box does not "focus" on these items. The NextLayerConnectorRef parameter is used to point to the second layer in the same way as a ConnectorReference is used for the Connector widget. The value of the NextFocusedWidget is used to point to the next widget in the focus sequence. Note that for the FocusLink the next widget may be on another UA's layer.
