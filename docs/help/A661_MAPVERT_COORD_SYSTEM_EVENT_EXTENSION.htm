A661_MAPVERT_COORD_SYSTEM_EVENT_EXTENSION (MapVertCoordSystemEventExtension)

The MapVertCoordSystemEventExtension is an extension which allows the CDS to report changes to the range and Projection Reference Point (RefGeoPosX and RefGeoPosY) on a MapVert widget (for example a pinch interaction could trigger a A661_EVT_VERT_RANGE_X or A661_EVT_VERT_RANGE_Y event). The UA can choose (via the EventIDArray parameter) which events it wants to receive among the available events added by this extension. The availability of these events for the CDS, and the way the CDS interprets the user interaction to send the values, are implementation dependent. For example,the event could be sent continuously when the user performs a drag and drop on the map, or only at the end of the gesture. Note that this extension is available on both the MapVert, MapVert_Source and MapExternalSource widgets. When this extension is applied on a MapVert_Source or MapExternalSource widget, it sends the events corresponding to user interactions on the MapVert parent of the MapVert_Source or MapExternalSource.
