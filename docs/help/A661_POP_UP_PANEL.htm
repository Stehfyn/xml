A661_POP_UP_PANEL (PopUpPanel)

Categories: Container, Graphical representation, Interactive

The PopUpPanel is a container intended for temporary display on top of all layers in its window. PopUpPanel has no static part. PopUpPanel widget should not be used as a regular Container. The UA or CDS can define the position of the Container according to the UAPositionFlag value. PopUpPanel widget has clipping capability.

ParameterChangeDescription

ParentIdentDIdentifier of the immediate container of the widget

PosYDRThe Y position of the widget reference point

SizeYDRThe Y dimension size (height) of the widget
