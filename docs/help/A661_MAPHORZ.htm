A661_MAPHORZ (MapHorz)

Categories: Container, Map management

A MapHorz widget consists of a rectangular region on the display, which contains reference information to enable the display of map features in the cockpit. The MapHorz widget enables multiple sources of information with different coordinate systems to be merged into a composite map image. MapHorz provides information for resolving coordinate system disparities among the map sources. MapHorz also has the responsibility for containing multiple map sources such that the data is merged properly into a composite representation.
