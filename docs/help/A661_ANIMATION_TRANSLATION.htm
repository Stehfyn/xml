A661_ANIMATION_TRANSLATION (AnimationTranslation)

Categories: Utility

The objective of this widget is to provide a means for performing a translation animation on one widget. The widget referenced in this AnimationTranslation widget must be defined in the Definition File before the AnimationTranslation widget. The behavior for this widget is specified in Section 3.2.11. Notes: - The translation values do not change the ARINC 661 target widget parameter values position. The result of the translation is added to the coordinate system transformation specified by the widget position and rotation. For example, if an AnimationTranslation is applied to a GpRectangle with a (PosX, PosY) position of (1000, 1000), and (ToValueX, ToValueY) = (4000, 4000), the graphical position of the GpRectangle at the end of the animation will be (5000, 5000) - If this animation receives a A661_DEACTIVATE, it will put back the state of the translation transformation to the identity transform (0, 0 translation).
